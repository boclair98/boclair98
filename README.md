# 이희승 (Heeseung Lee)

    안녕하세요! Java와 Spring Boot를 중심으로 비즈니스 가치를 구현하는 백엔드 개발자 이희승입니다.

    [Backend]
    - Java 17, Spring Boot 기반의 REST API와 서버 사이드 웹 애플리케이션을 개발합니다.
    - Spring MVC 구조에서 Controller, Service, Repository의 책임을 분리하고 유지보수 가능한 계층형 구조를 지향합니다.
    - Spring Data JPA, Querydsl을 활용해 도메인 중심의 데이터 접근 계층을 설계하고 동적 조회를 최적화합니다.
    - Spring Security, JWT 기반 인증/인가 흐름을 구현하고 사용자별 권한과 상태를 안정적으로 관리합니다.
    - JPA 영속성 컨텍스트와 트랜잭션 경계를 고려해 비즈니스 로직의 일관성을 높이는 개발을 추구합니다.

    [Database]
    - MySQL, Oracle, PostgreSQL 등 RDBMS 기반 테이블 설계와 SQL 쿼리 작성 경험이 있습니다.
    - 페이징, 정렬, 검색 조건, 계층형 게시판 등 서비스에서 자주 사용되는 데이터 조회 흐름을 구현합니다.
    - Oracle 기반 후불 요금제 및 할인 적용 로직 개발 경험을 바탕으로 데이터 중심 로직을 꼼꼼하게 다룹니다.

    [Data / AI / DX]
    - Python, Pandas, Numpy, Streamlit을 활용해 데이터 분석과 대시보드 구축을 수행했습니다.
    - KT AIVLE SCHOOL AI 및 DX 엔지니어 과정을 통해 데이터 전처리, 예측 모델링, DX 서비스 아키텍처를 경험했습니다.
    - 해수 담수화 공정 데이터를 분석하고 선형회귀 기반 전력 수요 예측 및 시각화 대시보드를 구현했습니다.

    [Frontend / App]
    - Thymeleaf, HTML, JavaScript를 활용해 백엔드 기능과 연결되는 화면을 구성합니다.
    - Android Studio 기반 음악 애플리케이션 프로젝트에서 오디오 재생, 커스텀 편집, 다운로드 기능을 구현했습니다.
    - 기능 구현뿐 아니라 사용자가 실제로 흐름을 이해하고 사용할 수 있는 인터페이스를 고민합니다.

    [Etc.]
    - GitHub와 Tistory를 통해 학습 과정과 문제 해결 기록을 남기고 있습니다.
    - 정보처리기사, SQLD, ADsP 자격을 보유하고 있으며 데이터와 백엔드 양쪽의 기초 체력을 함께 키워가고 있습니다.
    - 작게라도 직접 만들고, 원인을 파고들고, 기록으로 남기는 개발 습관을 중요하게 생각합니다.
